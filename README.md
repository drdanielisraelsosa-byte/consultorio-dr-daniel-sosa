# Consultorio Dr. Daniel Israel Sosa de Santiago

Sitio web profesional **one-page** (HTML/CSS puro, cero costo) para difusión de servicios médicos en León, Guanajuato.

## URL pública

**https://drdanielisraelsosa-byte.github.io/consultorio-dr-daniel-sosa/**

## Archivos

| Archivo | Rol |
|---------|-----|
| `index.html` | Contenido modular (editar solo textos entre comentarios `MÓDULO:`) |
| `styles.css` | Estilos mobile-first, tokens, tablas, siluetas/GIFs preparados |
| `GUIA-MAESTRA-EDICION.md` | **Guía completa** de edición, imágenes, republicación y checklist |
| `assets/` | Logo, foto, QR |

## Activar / verificar GitHub Pages

1. https://github.com/drdanielisraelsosa-byte/consultorio-dr-daniel-sosa/settings/pages  
2. **Deploy from a branch** → `main` → `/ (root)` → Save  
3. Esperar 1–2 minutos.
