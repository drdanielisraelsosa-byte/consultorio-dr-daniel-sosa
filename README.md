# Consultorio Dr. Daniel Israel Sosa de Santiago

Sitio web profesional **one-page** para difusión de servicios médicos en León, Guanajuato.

## URL pública (GitHub Pages)

Una vez habilitado GitHub Pages en el repositorio:

**https://drdanielisraelsosa-byte.github.io/consultorio-dr-daniel-sosa/**

### Cómo activar GitHub Pages (gratis, 1 minuto)
1. Entre a: https://github.com/drdanielisraelsosa-byte/consultorio-dr-daniel-sosa/settings/pages
2. En **Source** seleccione **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)`
4. Pulse **Save**
5. Espere 1-2 minutos y la URL estará activa.
